# Drone-Detection-With-Template-Matching
Bu proje, bilgisayarlı görü dersi kapsamında Şablon Eşleştirme (Template Matching) yöntemi kullanılarak geliştirilmiş bir drone tespit sistemidir. Projenin amacı, görüntülerde drone bulunup bulunmadığını tespit etmek ve drone bulunduğunda konumunu yeterli doğrulukla belirlemektir.
